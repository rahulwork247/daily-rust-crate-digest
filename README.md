# Daily Rust Crate Digest 🦀

## ⚙️ How It Works
Every day at 06:00 UTC, a GitHub Action queries crates.io, filters newly published crates, updates `feed.json`, `feed.xml`, and `index.html`, and deploys them to GitHub Pages for instant consumption.
